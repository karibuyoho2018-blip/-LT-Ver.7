# Pバイオハザード RE:2 LTver. シミュレーター v0.7

ブラウザだけで動く静的シミュレーターです。`index.html` を開けば使用できます。GitHub Pagesにもそのまま配置できます。

## v0.7で追加・修正したもの

- RE:先バレを **約1/99.9・期待度50%** に変更
- RE:カスタムON時の通常時大当たりは **100%先バレ経由**
- 先バレ音とRE:画面の開始タイミングを同期
- 先バレ後を2段階操作に変更
  1. 先バレ発生
  2. 「発展先を見る」
  3. リーチ先・期待度表示
  4. 「当落結果を見る」
  5. 当落演出
- 「発展先を見る」は先バレ音の尺に関係なく、発生直後から操作可能
- 通常時の先バレ大当たりでも大当たり音を再生
- 49%のRUSH非突入大当たりに **「RUSH 突入ならず → 通常時へ」全画面演出**を追加
- v0.6までの背景画像、右打ち1回転/10回転、残保留、タイラント演出、音量調整、スマホ対応を継続

## 先バレ確率について

通常時図柄揃いが1/199.8で、すべての大当たりを先バレ経由にしつつ先バレ期待度を50%にすると、数学上の先バレ発生率は約1/99.9になります。
そのためユーザー指定の「約1/110」を目安にしつつ、期待度50%と全当たり先バレ経由の両立を優先して約1/100に設定しています。

## 基本スペック

- 通常時図柄揃い: 1/199.8
- 右打ち中: 1/45.8
- 特図1:
  - 1%: 10R (1500個) → HAZARD RUSH PREMIUM
  - 50%: 2R (300個) → HAZARD RUSH
  - 49%: 2R (300個) → 通常
- HAZARD RUSH: ST53回 + 残保留4個
- SURVIVAL CHANCE: ST53回。ST1～52回の大当たりでXTREME
- XTREME: ST87回 + 残保留4個
- ST最終変動 + 残保留4個の当たりは33% SURVIVAL / 67% HAZARD

## 通常時先バレ発展

- ゾンビ群リーチ ★3 = 30%
- リッカーリーチ ★3 = 30%
- アリゲーターリーチ ★3.5 = 50%
- G STAGE 2 リーチ ★3.5 = 50%
- G STAGE 3 リーチ ★4 = 70%
- 全回転リーチ = 1% PREMIUM直行時のみ

## SURVIVAL CHANCE

- 通常 / SHORT RANGE = 30%
- EAST PASSAGE = 40%
- SHOWER ROOM = 50%
- CHIEF’S OFFICE = 60%
